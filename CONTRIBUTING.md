# Contributing

RoBridge is public [MIT](LICENSE). Fork the repo and customize your own copy. Do not expect write access to `main` — that branch is maintained by LeapVerse/Allusia1.

To propose a change upstream:

1. Fork [Allusia1/RoBridge](https://github.com/Allusia1/RoBridge).
2. Work on your fork.
3. Open a pull request against this repo.

Custom versions are allowed via fork under MIT.
